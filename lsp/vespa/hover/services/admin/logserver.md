## logserver

Specifies a host on which to run the [Vespa Log Server](https://docs.vespa.ai/en/reference/logs.html#log-server) service. If not specified, the logserver is placed on the [adminserver](https://docs.vespa.ai/en/reference/services-admin.html#adminserver), like in the [example](https://github.com/vespa-engine/sample-apps/blob/master/examples/operations/multinode-HA/services.xml).
[Read more](https://docs.vespa.ai/en/reference/services-admin.html#logserver)
