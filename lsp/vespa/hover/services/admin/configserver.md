## configserver

Specifies a host on which to run the [Configuration Server](https://docs.vespa.ai/en/operations-selfhosted/configuration-server.html) service. If contained directly below `<admin>` you may only have one, so if you need to configure multiple instances of this service, contain them within the [`<configservers>`](https://docs.vespa.ai/en/reference/services-admin.html#configservers) element.
[Read more](https://docs.vespa.ai/en/reference/services-admin.html#configserver)
