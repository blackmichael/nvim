## consumer

Configure a metrics consumer. The metrics contained in this element will be exported to the consumer with the given id. `consumer` is a request parameter in [/metrics/v1/values](https://docs.vespa.ai/en/reference/metrics-v1.html), [/metrics/v2/values](https://docs.vespa.ai/en/reference/metrics-v2.html) and [/prometheus/v1/values](https://docs.vespa.ai/en/reference/prometheus-v1.html).

Add `metric` and/or `metric-set` children.
[Read more](https://docs.vespa.ai/en/reference/services-admin.html#consumer)
