## inherits

Wrapper element for information about which chains, if any, a chain should inherit, and how. Contained in [request-chain](https://docs.vespa.ai/en/reference/services-http.html#chain) and [response-chain](https://docs.vespa.ai/en/reference/services-http.html#chain). Sub-elements:

* (inherited) [chain](https://docs.vespa.ai/en/reference/services-http.html#inheritedchain)
* [exclude](https://docs.vespa.ai/en/reference/services-http.html#exclude)
