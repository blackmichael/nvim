## client

Vespa Cloud only. Child element of [clients](https://docs.vespa.ai/en/reference/services-container.html#clients). Use to configure security credentials for a container cluster, using [certificate](https://docs.vespa.ai/en/reference/services-container.html#certificate) and/or [token](https://docs.vespa.ai/en/reference/services-container.html#token).
