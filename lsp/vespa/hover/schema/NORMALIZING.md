## normalizing

Contained in [field](https://docs.vespa.ai/en/reference/schema-reference.html#field). Sets [normalizing](https://docs.vespa.ai/en/linguistics.html#normalization) to be done on this field. The default is to normalize.

```
normalizing: [normalizing-type]
```
